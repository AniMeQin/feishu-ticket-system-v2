# 飞书 IT 工单系统 V2

基于腾讯云 SCF Web 函数和飞书多维表格的 IT 工单服务。安装与字段说明见 `docs/字段与部署.md`。

## 使用教程

第一次使用请看 [使用教程](docs/使用教程.md)：包含报修人提交与确认、IT 接单与处理、状态说明和常见问题。部署与运维分别参阅 [字段与部署](docs/字段与部署.md) 和 [运维与故障排查](docs/运维与故障排查.md)。

系统问题反馈请发邮件至 [1121840881@qq.com](mailto:1121840881@qq.com)。日常报修仍使用飞书 V2 报修表单；反馈邮件的填写建议见[使用教程](docs/使用教程.md#问题反馈)。

## 本地验证

```sh
npm test
npm run check
```

部署时在云函数环境变量中配置飞书应用凭据、表格标识和内部任务令牌。项目不提供生产凭据。`src/legacy-confirmation-bounds.json` 是仅用于历史工单的私有证据文件，不进入仓库；缺少它时服务仍可运行，新工单按实际处理完成时间计时。部署包和线上配置应在部署前单独核对，不能直接将仓库内容视为已验收的生产包。

历史迁移数据、运行结果、日志、补丁和部署备份保留在本机，均被 `.gitignore` 排除。
